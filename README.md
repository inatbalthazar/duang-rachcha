# ดูดวงรายวัน

เว็บแอปสร้างภาพ "ดูดวงรายวัน" 1080×1350 สำหรับโพสต์ลงเพจ Facebook **รัชฌา ปัททุม** ใช้งานบนมือถือ Android ได้ (ติดตั้งลงหน้าจอหลักแบบ PWA)

เว็บจริง: https://duang-rachcha.vercel.app

## ใช้งานทุกวัน

1. กด **คัดลอกคำสั่ง** แล้วไปวางในแอป AI (Claude, ChatGPT, Gemini ฯลฯ)
2. คัดลอกคำตอบทั้งหมดกลับมา กด **วางคำตอบจาก AI**
3. ระบบสร้างภาพดวงทั้ง 7 วัน แคปชันแบบสั้น และคำทำนายฉบับเต็มสำหรับคอมเมนต์แรก: เว้นบรรทัดระหว่างส่วน ใช้คำลงท้ายแบบผู้หญิง ใส่แฮชแท็ก `#ดวงวัน…` ของวันนั้น และตรวจคำที่ผิดกฎ Facebook
4. กด **แชร์ภาพไป Facebook** แล้ววางแคปชัน โพสต์เสร็จกด **คัดลอกคอมเมนต์** ไปวางใต้โพสต์ หรือกด **โพสต์ลงเพจเลย** ถ้าตั้งค่า Page token ไว้แล้ว (ใส่คอมเมนต์ให้เอง)

ทุกวันอาทิตย์ เลือก **ดวงประจำสัปดาห์** ในขั้นที่ 1 (สัปดาห์หน้า = จันทร์ถึงอาทิตย์ถัดไป) ภาพจะเป็นการ์ด 3 + 4 ใบ มีคำทำนาย ความรัก คนโสด และสุขภาพแบบย่อในภาพ

มี **ดวง 12 ราศี** ทั้งรายวันและประจำสัปดาห์ด้วย ภาพเป็นการ์ด 3 × 4 ใบ (งาน เงิน ความรัก สุขภาพ สีและเลขมงคล) ช่วงวันที่ของแต่ละราศีใช้แบบสุริยยาตรไทย (เมษ 13 เม.ย. – 13 พ.ค.)

ทุกแบบโพสต์เหมือนกัน: ภาพมีป้าย "อ่านคำทำนายฉบับเต็มที่คอมเมนต์" แคปชันเป็นแบบสั้น และคำทำนายฉบับละเอียดอยู่ในคอมเมนต์แรก (กด **คัดลอกคอมเมนต์** หลังโพสต์ หรือ **โพสต์ลงเพจเลย** จะใส่คอมเมนต์ให้เอง)

ดีไซน์ภาพ (โทนสี ลายพื้นหลัง ท่ามาสคอต ฯลฯ) จะสุ่มใหม่ตามวันที่ และไม่ซ้ำกับภาพที่โพสต์ไปใน 14 วันล่าสุด

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `app/` | ตัวเว็บที่ขึ้น Vercel: `index.html` (หน้าจอ), `engine.js` (วาดภาพ อ่านคำตอบ AI ตรวจแคปชัน สร้าง prompt), `sw.js` + `manifest.webmanifest` (ติดตั้งและใช้ออฟไลน์), `mascot/` (ภาพมาสคอต 8 ท่า) |
| `mascot-src/` | ภาพต้นฉบับมาสคอต และสคริปต์ตัดพื้นหลัง (`cut2.py` คือชุดที่ใช้อยู่) |
| `duang-studio.html` | เวอร์ชันแรกสำหรับคอม (5 วัน) เก็บไว้อ้างอิง |

ไม่มีขั้นตอน build เป็นไฟล์ static ล้วน

## ทดลองในเครื่อง

```bash
python -m http.server 8765
```

แล้วเปิด http://localhost:8765/app/

## Deploy

```bash
cd app
vercel deploy --prod
```

## ทำมาสคอตใหม่

วางภาพต้นฉบับไว้ใน `mascot-src/` แก้ตำแหน่งครอปใน `cut2.py` แล้วรัน:

```bash
cd mascot-src
python cut2.py
```

ไฟล์ใหม่จะออกไปที่ `app/mascot/` และได้ `check.png` ไว้ดูผลบนพื้นสีเข้ม ถ้าเปลี่ยนชื่อท่า ต้องแก้รายชื่อใน `engine.js` (DIMS → `mascot`) และ `sw.js` ด้วย

# ดูดวงรายวัน

เว็บแอปสร้างภาพ "ดูดวงรายวัน" 1080×1350 สำหรับโพสต์ลงเพจ Facebook **รัชฌา ปัททุม** ใช้งานบนมือถือ Android ได้ (ติดตั้งลงหน้าจอหลักแบบ PWA)

เว็บจริง: https://duang-rachcha.vercel.app

## ใช้งานทุกวัน

1. กด **คัดลอกคำสั่ง** แล้วไปวางในแอป AI (Claude, ChatGPT, Gemini ฯลฯ)
2. คัดลอกคำตอบทั้งหมดกลับมา กด **วางคำตอบจาก AI**
3. ระบบสร้างภาพดวงทั้ง 7 วัน แคปชันแบบสั้น และคำทำนายฉบับเต็มสำหรับคอมเมนต์แรก: เว้นบรรทัดระหว่างส่วน ใช้คำลงท้ายแบบผู้หญิง ใส่แฮชแท็ก `#ดวงวัน…` ของวันนั้น และตรวจคำที่ผิดกฎ Facebook
4. กด **แชร์ภาพไป Facebook** แล้ววางแคปชัน โพสต์เสร็จกด **คัดลอกคอมเมนต์** ไปวางใต้โพสต์ หรือกด **โพสต์ลงเพจเลย** ถ้าตั้งค่า Page token ไว้แล้ว (ใส่คอมเมนต์ให้เอง)

มีโพสต์ 3 แบบ เลือกในขั้นที่ 1

| แบบ | ภาพ | คำทำนายฉบับเต็มอยู่ที่ |
|---|---|---|
| ดวงวันเกิด รายวัน | 1 ภาพ (7 วันในภาพเดียว) | คอมเมนต์แรก (ราว 2,000–3,000 ตัวอักษร) แคปชันแบบสั้น |
| ดวงวันเกิด ประจำสัปดาห์ (ลงวันอาทิตย์) | 8 ภาพ: ปก + ภาพละ 1 วันเกิด | แคปชัน |
| ดวง 12 ราศี ประจำเดือน | 13 ภาพ: ปก + ภาพละ 1 ราศี | แคปชัน |

Facebook รับคอมเมนต์ได้ไม่เกิน 8,000 ตัวอักษร ดวงรายสัปดาห์ (ราว 4,500–6,200) และดวง 12 ราศี (ราว 6,000–8,500) จึงใส่คำทำนายในแคปชันแทน ซึ่งรับได้ถึง 63,206 ตัวอักษร ถ้าคอมเมนต์ของดวงรายวันยาวเกิน แอปจะเตือน

แบบรายสัปดาห์และรายเดือน AI ตอบเป็น JSON อย่างเดียว แล้วแอปจัดแคปชันฉบับเต็มเอง (หัวข้อแต่ละวัน/ราศี การงาน การเงิน ความรัก สุขภาพ ข้อแนะนำ สีและเลขมงคล) ช่วงวันที่ของแต่ละราศีใช้แบบสุริยยาตรไทย (เมษ 13 เม.ย. – 13 พ.ค.)

### โพสต์อัตโนมัติ (ไม่บังคับ)

ใส่ Page ID และ Page access token ใน ตั้งค่า → โพสต์ตรงเข้าเพจ แล้วปุ่ม **โพสต์ลงเพจเลย** จะโพสต์ให้ทั้งหมดในแตะเดียว: ดวงรายวันได้ภาพ + แคปชัน + คอมเมนต์แรก แบบชุดภาพจะอัปโหลดทุกภาพแล้วโพสต์เป็นโพสต์เดียวพร้อมแคปชัน token เก็บในมือถือเครื่องนั้นเท่านั้นและส่งไปที่ Facebook อย่างเดียว

วิธีได้ token ที่ไม่หมดอายุ (ทำครั้งเดียวบนคอม):

1. สร้างแอปที่ https://developers.facebook.com (ประเภท Business) ด้วยบัญชีที่เป็นแอดมินเพจ
2. เปิด Graph API Explorer เลือกแอปนั้น กด Generate Access Token ให้สิทธิ์ `pages_show_list`, `pages_read_engagement`, `pages_manage_posts`, `pages_manage_engagement`
3. แปลงเป็น long-lived user token ที่ Access Token Debugger (ปุ่ม Extend Access Token)
4. ใน Graph API Explorer ใช้ token นั้นเรียก `me/accounts` จะได้ `id` (Page ID) และ `access_token` ของเพจ ซึ่งไม่หมดอายุ
5. ใส่ทั้งสองค่าในแอปบนมือถือแม่ แล้วกด **ทดสอบ**

ดีไซน์ภาพ (โทนสี ลายพื้นหลัง ท่ามาสคอต ฯลฯ) จะสุ่มใหม่ตามวันที่ และไม่ซ้ำกับภาพที่โพสต์ไปใน 14 วันล่าสุด

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `app/` | ตัวเว็บที่ขึ้น Vercel: `index.html` (หน้าจอ), `engine.js` (วาดภาพ อ่านคำตอบ AI ตรวจแคปชัน สร้าง prompt), `sw.js` + `manifest.webmanifest` (ติดตั้งและใช้ออฟไลน์), `mascot/` (ภาพมาสคอต 8 ท่า) |
| `mascot-src/` | ภาพต้นฉบับมาสคอต และสคริปต์ตัดพื้นหลัง (`cut2.py` คือชุดที่ใช้อยู่) |
| `duang-studio.html` | เวอร์ชันแรกสำหรับคอม (5 วัน) เก็บไว้อ้างอิง |

ไม่มีขั้นตอน build เป็นไฟล์ static ล้วน

## ทดลองในเครื่อง

```bash
python -m http.server 8765
```

แล้วเปิด http://localhost:8765/app/

## Deploy

```bash
cd app
vercel deploy --prod
```

## ทำมาสคอตใหม่

วางภาพต้นฉบับไว้ใน `mascot-src/` แก้ตำแหน่งครอปใน `cut2.py` แล้วรัน:

```bash
cd mascot-src
python cut2.py
```

ไฟล์ใหม่จะออกไปที่ `app/mascot/` และได้ `check.png` ไว้ดูผลบนพื้นสีเข้ม ถ้าเปลี่ยนชื่อท่า ต้องแก้รายชื่อใน `engine.js` (DIMS → `mascot`) และ `sw.js` ด้วย
